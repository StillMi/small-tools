# StillMi 的小工具 (StillMi's Small Tools)

一个 Minecraft **1.21.1 / NeoForge 21.1.x** 的整合小工具模组。

> **隶属关系**：本模组是上位工程，**已包含**「末影传送石」的全部内容。
> 装了本模组就不需要再单独装传送石模组 —— 两者不建议同时安装。

## 创造模式

本模组在创造模式里**有自己独立的标签页**「StillMi 的小工具」，图标是末影传送石。
页里现在有六样东西：末影传送石、地牢传送石、同伴传送石、附魔洗炼石、附魔强化器、
浓缩液态青金，不再和原版工具类混在一起。

## 包含的内容

### 末影传送石

8 块黑曜石 + 1 颗末影珍珠合成。长按右键引导 4 秒，在你瞄准的位置开一座双向传送门，
另一端落在**这块石头自己绑定的坐标**附近。

- **潜行 + 右键**设定坐标，一块石头**只能设定一次**，设定后不可更改；
- 没绑过坐标的石头使用配置文件里的默认值；
- 每块石头各自记各自的目的地，想要多个地方就多做几块。

### 地牢传送石

8 块金锭 + 1 颗末影珍珠合成。另一端开在附近的**地牢**（原版刷怪笼房间）里。
目的地由世界决定，**玩家不能设定坐标**。

### 附魔洗炼石

**4 金块 + 4 钻石 + 1 黑曜石**（四角金块、四边钻石、中间黑曜石）。

右键打开洗炼界面，把一件**已附魔的武器或工具**放进槽里（未附魔的放不进去），
然后：

1. 挑一个想替换的附魔词条；
2. 服务端为该词条随机出**三条同等级**的其它附魔；
3. 选一条，原来那条被替换掉，**洗炼石消失**。

候选不会和物品上已有的附魔重复，也只会出现**能附在这件物品上**的附魔
（不会出现"锋利"跑到镐子上）。等级沿用被替换那条，
但不超过候选自身上限（比如"经验修补"最高只有 I 级）。

关界面会把槽里的物品还给你，中途放弃不消耗洗炼石。

### 附魔强化器

**4 金块 + 4 钻石块 + 1 黑曜石**（四角金块、四边钻石块、中间黑曜石）。

右键打开强化界面，把一件**已附魔**的物品放进去，然后：

1. 投入**浓缩液态青金**，攒够这一级需要的强化经验（一次投满，不接受零散）；
2. 点"强化"，次数 +1，物品上的强化次数上限 **5 次**。

每次强化的效果：

- 物品上的附魔**少于 3 条**时，优先**补一条新的 1 级附魔**（跳过诅咒，也只会挑能附上去的）；
- 已经有 3 条及以上时，随机把其中一条**升 1 级**（已达上限的那条会被跳过）。

各级需要的经验是 **10 / 30 / 70 / 110 / 160**（合计 380 点）；
一颗液态青金折算 5 点，所以实际要投 **2 / 6 / 14 / 22 / 32 颗**，五级总共 76 颗。

强化次数和"已经投进去多少经验"都存在**物品自身**的数据组件上，
所以换手、放箱子、下线再上都不会丢；也正因为记在物品上，
同一个人反复强化同一件装备不会越强越便宜。

强化器**不能拿来强化自己** —— 它本身没有附魔，强行强化会卡在永远无法完成的半成品状态。

物品说明里会写出 `已强化 N / 5 次`，以及 `下一次需要 X 经验（Y 颗液态青金）`；
满 5 次后那行变成红色的"已达强化上限"。

### 浓缩液态青金

青金石直接烧出来的东西 —— **1 青金石 → 1 液态青金**，
熔炉 200 tick（10 秒），高炉 100 tick（5 秒），两者都是 0.35 经验。

它只有强化器一个用途，本身不能吃、不能酿、不当燃料。

### 同伴传送石

**4 金锭 + 4 末影珍珠 + 1 指南针**（四角金锭、四边末影珍珠、中间指南针）。

右键打开选人界面，名单是服务端现算的：**同维度在前、按距离由近到远**，
跨维度的排在最后并单独标出来（不显示一个没有意义的距离数字）。

1. 点一位玩家，发出请求；
2. 对方屏幕上弹出确认框，显示你是谁、离多远、还剩几秒；
3. 点"同意"开始 **10 秒**倒计时，两边每秒钟各收到一次剩余秒数；
4. 倒计时结束，你落在目标**旁边**那一格，石头消耗掉。

它不是"开一扇门"，是**一次性的一叠票**，所以不用耐久、可以堆叠。
传送落点在目标周围 3 格内找一格能站人的地方（脚下要结实、不是水、不是树叶），
找不到就取消并说明原因。

**任何一步失败都不消耗石头**：对方下线、你中途把石头丢掉、目标附近站不下人，
都只取消。请求本身 30 秒没人回应也会自动作废。

按 ESC 等同于拒绝 —— 不能什么都不做就把框关掉，那样对方只能干等到超时。

两项都能在配置里调：`companionDelaySeconds`（同意后等几秒，默认 10）、
`companionRequestSeconds`（请求最多等多久，默认 30）。

### 传送门

- 门面直接引用原版 `minecraft:block/nether_portal`（16×512 / 32 帧贴图 + 原版自带的 `.mcmeta`），
  本模组**没有**自己的门贴图，`assets/smalltools` 下也**没有**对应的 `.mcmeta`；
- 几何是厚度 4/16 的薄片，正反两面都贴图，四个朝向各自旋转；
- 进门要站够 **4 秒**（原版 `playersNetherPortalDefaultDelay`），期间有下界门的
  镜头扭曲和 `PORTAL_TRIGGER` 环境音；
- 传送后 5 秒内不能再传（`teleportDelaySeconds`，默认值是原版 0.5 秒的 10 倍，
  填 0 就退回原版的 10 tick）；
- 结构为 4×5 门框 + 2×3 门面 + 门前一格两宽台阶，无高台、无支撑柱。

### 次数规则

每块石头 3 次开门机会（`durability`），用完后物品消失。
每次开门后每人可往返 2 次（`roundTrips`）。次数按人单独计算：
**创造者的次数用尽会关闭整对门**，其他玩家用尽只是自己不能再传。

同伴传送石不参与这套规则：它没有门，也没有耐久，用一次整颗消失。

## 配置

`config/smalltools-common.toml`

```toml
[general]
    channelSeconds = 4          # 引导秒数
    cooldownSeconds = 60        # 物品冷却
    teleportDelaySeconds = 5    # 传送后多久能再传（0 = 退回原版 0.5 秒）
    roundTrips = 2              # 每人往返次数
    aimDistance = 24            # 能开门的准星距离
    dungeonRadiusChunks = 20    # 找地牢的搜索半径（区块）
    companionDelaySeconds = 10  # 同伴传送石：对方同意后等几秒
    companionRequestSeconds = 30  # 同伴传送石：请求最多等多久

[destination]
    targetX = 1000              # 没绑定坐标的石头用这里的默认值
    targetY = 64
    targetZ = 1000
    targetSearchRadius = 16
```

## 构建

本工程**不复制** NeoForm 重编译产物和 Gradle 依赖缓存（几百 MB），
`tools/compile.ps1` 会回落到同级目录的 `enderportal` 工程取依赖。

```powershell
# 本地没有 GDK 的环境（沙箱）用这条
powershell -ExecutionPolicy Bypass -File tools\compile.ps1   # -> build\classes
python tools\package.py                                      # -> build\libs\smalltools-<版本>.jar
```

有 Gradle 的环境直接用 `gradlew build`。

### 部署到本地测试环境

每次打包后执行：

```powershell
python tools\deploy.py
```

它会把最新 `smalltools-*.jar` 复制到
`H:\PCL\.minecraft\versions\1.21.1\mods`，并**删掉比这次部署更旧的历史版本**
（只匹配 `smalltools-*.jar`，不动其他模组；更高版本的已装 jar 会保留）。
复制走"临时文件 → SHA256 校验 → `os.replace` 原子替换"，游戏正开着导致写不进去时
旧 jar 原样保留，不会出现"删干净了又拷失败"的空目录。

> `tools/compile.ps1` 必须存成 **UTF-8 with BOM**，否则 Windows PowerShell 5.1
> 会按 GBK 解析中文注释而报语法错。用编辑器改完它记得确认 BOM 还在。

## 产物

- `build/libs/smalltools-<版本>.jar`
- 装到 NeoForge 21.1.x 的 `mods/` 目录即可
